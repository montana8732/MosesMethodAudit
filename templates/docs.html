The Moses Method Structures, LLC - Healthcare Compliance & Audit Engine

Audit Endpoint

POST /audit

Sends raw text or log payloads for real-time PHI/PII redaction and database auditing. Requires header X-API-KEY.

Request Headers

Content-Type: application/json
X-API-KEY: MOSES_METHOD_SECRET_KEY_2026

JSON Request Payload

{
  "log_data": "Patient MRN-654321 was evaluated under ICD-10 code E11.9."
}

JSON Response Structure

{
  "agency": "The Moses Method Structures, LLC",
  "audit_type": "Healthcare AI Bot Log Scan",
  "compliance_status": "FAILED COMPLIANCE",
  "total_violations": 2,
  "violation_details": [
    "CRITICAL: Potential Medical Record Number (MRN/PHI) detected.",
    "CRITICAL: Potential ICD-10 Clinical Diagnosis Code (PHI) detected."
  ],
  "sanitized_log": "[REDACTED-MRN] was evaluated under [REDACTED-ICD10]."
}

Integration Examples

cURL (Terminal)

curl -X POST http://localhost:5000/audit \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: MOSES_METHOD_SECRET_KEY_2026" \
  -d '{"log_data": "Patient MRN-654321 evaluated under ICD-10 code E11.9."}'

Python (requests)

import requests

url = "http://localhost:5000/audit"
headers = {
    "Content-Type": "application/json",
    "X-API-KEY": "MOSES_METHOD_SECRET_KEY_2026"
}
payload = {"log_data": "Patient MRN-654321 evaluated under ICD-10 code E11.9."}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

Status Codes

Code Description
200 OK Scan completed successfully and logged to SQLite.
400 Bad Request Missing required log_data key in JSON payload.
401 Unauthorized Missing or invalid X-API-KEY header.
